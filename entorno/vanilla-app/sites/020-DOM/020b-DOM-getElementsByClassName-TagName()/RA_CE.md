# 020b — RA y CE

## Resumen técnico

A partir de un clic se recogen varios párrafos por clase y varios títulos por etiqueta. El script recorre esas colecciones y escribe el texto encontrado.

## Resultados de Aprendizaje trabajados

RA2, RA5 y RA6. El enganche del clic ya visto en 020a solo se usa para disparar esta búsqueda.

## Criterios de Evaluación acreditados

- **RA2.f** Un bucle recorre la colección de elementos encontrados.
- **RA5.b** El clic de cada botón lanza la búsqueda.
- **RA5.d** El manejador lee la colección y vuelca el texto en el resultado.
- **RA6.b** `getElementsByClassName` y `getElementsByTagName` son los métodos nuevos. `getElementById` solo localiza los botones.
- **RA6.c** Se recorre un grupo de nodos del documento, no un único elemento.

No acredita otra vez las seis formas de enganchar un clic del paso anterior. No hay creación de nodos ni formulario.
