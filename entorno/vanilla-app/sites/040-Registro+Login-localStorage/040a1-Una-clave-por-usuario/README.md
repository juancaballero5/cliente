# 040a1 — Una clave por usuario

Partís de `030f-Rutas`. El registro, el login, el menú y la página de usuarios siguen con cookies. Este paso añade una práctica de Storage: cada cuenta se guarda en `localStorage` con su nombre de usuario como clave.
