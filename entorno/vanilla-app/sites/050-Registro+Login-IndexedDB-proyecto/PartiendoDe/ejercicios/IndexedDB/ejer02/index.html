Usuario desde la API

Guardamos cada cuenta en IndexedDB.

Almacén usuarios; clave primaria: el campo usuario.

Cada cuenta añade la dirección. La foto es un Blob, no texto Base64.

Pedir a la API rellena el formulario. El nombre, el teléfono y la dirección salen de randomuser.
La casilla elige la foto: marcada, un Blob de otra API; sin marcar, la dirección de la miniatura de randomuser.

El botón de espera no bloquea la página: puedes seguir escribiendo y guardar mientras cuenta.
