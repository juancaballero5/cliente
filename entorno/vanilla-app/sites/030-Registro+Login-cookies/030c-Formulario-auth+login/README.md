# 030c — Iniciar sesión con la cookie del usuario

Partís de `030b-Formulario-auth+registro`. El registro se queda. Login deja de abrir la página en construcción y comprueba la cookie del usuario. Si la contraseña coincide, guarda otra cookie con la clave `usuario`.

**URL:** `http://localhost:4300/030-Registro+Login-cookies/030c-Formulario-auth+login/`

Login: `http://localhost:4300/030-Registro+Login-cookies/030c-Formulario-auth+login/login.html`
