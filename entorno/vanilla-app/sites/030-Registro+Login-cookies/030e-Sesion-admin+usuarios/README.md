# 030e — Alta, listado, edición y borrado de usuarios

Partís de `030d-Sesion-auth+menu`. El registro, el login y el menú de sesión se quedan. Este paso añade el enlace Usuarios, solo si la sesión es `admin`, y la página que da de alta, lista, edita y borra las cookies de las cuentas.

**URL:** `http://localhost:4300/030-Registro+Login-cookies/030e-Sesion-admin+usuarios/`

Usuarios: `http://localhost:4300/030-Registro+Login-cookies/030e-Sesion-admin+usuarios/usuarios.html`
