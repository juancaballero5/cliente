# 060a1 — Usuario en la API

Partís de `050f-Rutas`. El registro, el login y el menú siguen en IndexedDB. Las dos bases `Usuarios-DB` y `Sesion-DB` pasan a ser una sola, `accesoDB`, con los almacenes `usuarios` y `sesion`. Esta carpeta añade la práctica APINodeJS: la cuenta de ese formulario se guarda en MySQL, a través de la API en Node.js. La foto deja de ser un `File` y se guarda como texto.
