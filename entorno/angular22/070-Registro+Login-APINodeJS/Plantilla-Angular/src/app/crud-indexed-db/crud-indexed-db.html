Usuario en IndexedDB

Guardamos cada cuenta en IndexedDB.

Cada cuenta añade la dirección.
Si la casilla está marcada, la foto se guarda como Blob.
Si no, se guarda como texto.

Pedir a la API rellena el formulario.
El nombre, el teléfono y la dirección salen de randomuser.
La casilla elige la foto:
- marcada, un Blob de otra API;
- sin marcar, la dirección de la miniatura de randomuser.

Almacén usuarios; clave primaria: el campo usuario.

El botón de espera no bloquea la página: puedes seguir escribiendo y guardar mientras cuenta.
