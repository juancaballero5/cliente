Usuarios en LocalStorage

Guardamos las cuentas juntas en localStorage.

Clave: usuarios. El valor es un objeto JSON con todas las cuentas.

Cada cuenta añade la dirección.
La foto se guarda como texto.
Si la casilla pide un Blob, se convierte antes de guardar.

Pedir a la API rellena el formulario.
El nombre, el teléfono y la dirección salen de randomuser.
La casilla elige la foto:
- marcada, un Blob de otra API;
- sin marcar, la dirección de la miniatura de randomuser.

       

El botón de espera no bloquea la página:
puedes seguir escribiendo y guardar una cuenta.
