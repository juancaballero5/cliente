# 04 — Extensiones de VS Code (bloque 02)

**Secuencia:** [README.md](README.md) → … → **04 extensiones**

Si aún no has instalado → [01 instalación](README-01-instalacion.md)

El script del bloque 02 instala las extensiones del curso, quita algunas antiguas que ya no usamos y deja un `settings.json` sencillo.

---

## Extensiones instaladas

| Extensión | Para qué | Cuándo |
|-----------|----------|--------|
| **Docker** | Ver contenedores y logs | Desde `docker compose up` |
| **WSL** | Abrir el proyecto en Ubuntu | Solo Windows (WSL) |
| **GitLens** | Historial Git en el editor | Cuando uséis Git |
| **Angular Language Service** | Autocompletado Angular | Módulo Angular |
| **React Snippets** | Atajos JSX/TS | Módulo React |
| **HTML CSS Support** | Ayuda en HTML/CSS | Vanilla y frontends |
| **Prettier** | Formatear al guardar | Siempre |
| **Database Client** | Consultar MySQL | Trabajo con BBDD |

---

## No instalamos (a propósito)

| Extensión | Motivo |
|-----------|--------|
| **GitHub Copilot** | Requiere licencia del centro |
| Temas, iconos, Tailwind, ESLint… | No son imprescindibles para el curso |

Si tienes otras extensiones, puedes dejarlas o quitarlas a mano.

---

## settings.json

Fuente 14, tabulación 2, Prettier al guardar.  
Si ya existía un `settings.json`, se guarda una copia en `settings.json.bak`.
